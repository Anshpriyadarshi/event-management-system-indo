# Admin

## Overview

The Admin is responsible for managing and maintaining the Event Management System. The Admin controls users, events, roles, permissions, and system data to ensure that the system operates smoothly and securely.

## Responsibilities

- Manage users and user accounts.
- Create, update, and delete events.
- Assign roles and permissions to users.
- Monitor event activities.
- Manage event-related information.
- Maintain system records.
- Review and manage reports.
- Monitor system security.
- Handle user issues and requests.
- Ensure that event information is accurate and up to date.

## User Management

The Admin can:

- Add new users.
- Update user information.
- Remove users.
- View registered users.
- Assign roles.
- Manage user permissions.

### User Roles

| Role | Responsibility |
|------|----------------|
| Admin | Manage the complete system |
| Event Manager | Plan and manage events |
| Technical Manager | Manage technical requirements |
| Treasurer | Manage event finances |
| Volunteer | Assist with event activities |
| Attendee | Register and participate in events |

## Event Management

The Admin can manage:

- Event name
- Event description
- Event date and time
- Venue
- Event capacity
- Registration status
- Event status
- Event organizers

### Event Status

- Planned
- Upcoming
- Ongoing
- Completed
- Cancelled

## Permissions

The Admin should ensure that users can only access features relevant to their assigned roles.

| Feature | Admin | Event Manager | Treasurer | Technical Manager |
