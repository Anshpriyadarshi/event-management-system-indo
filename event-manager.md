# Event Management System — Roles

### 👑 Event Manager

The Event Manager is responsible for the overall planning and execution of the event. They create the event, assign tasks, coordinate with different managers, monitor progress, handle major issues, and ensure the event is completed successfully.

### 💰 Treasurer

The Treasurer manages the financial activities of the event. They handle the budget, track income and expenses, approve payments, maintain transaction records, and prepare financial reports.

### 💻 Technical Manager

The Technical Manager handles all technical requirements of the event. They manage equipment, internet, audio/video systems, registration software, technical setup, and provide technical support during the event.

### 🤝 Sponsorship Manager

The Sponsorship Manager manages relationships with sponsors. They find potential sponsors, create sponsorship proposals, negotiate deals, track sponsorship payments, and ensure sponsors receive their promised benefits.

### 📋 Event Coordinator

The Event Coordinator manages the day-to-day operations of the event. They coordinate schedules, venues, activities, volunteers, participants, and different teams to ensure everything runs according to plan.
