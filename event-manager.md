# Event Manager

## Overview

The Event Manager is responsible for planning, organizing, coordinating, and managing the complete event. They work with different teams to ensure the event is completed successfully and on schedule.

## Responsibilities

- Plan and organize the event.
- Set event goals, date, time, and venue.
- Coordinate with different teams and managers.
- Create and monitor the event schedule.
- Assign tasks to team members.
- Coordinate with vendors and guests.
- Monitor event preparation and progress.
- Handle problems and unexpected situations.
- Ensure the event runs smoothly.

## Event-Day Responsibilities

- Ensure all teams are ready before the event.
- Monitor the event schedule.
- Coordinate with guests and speakers.
- Resolve unexpected problems.
- Communicate with team leaders.
- Ensure attendees have a smooth experience.

## Workflow

1. Define event requirements.
2. Prepare the event plan and schedule.
3. Assign responsibilities to teams.
4. Coordinate with vendors and managers.
5. Monitor event preparation.
6. Manage the event on the day.
7. Collect feedback and prepare the final report.
